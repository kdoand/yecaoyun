## 三种线路怎么选？

**普通 BGP**：带宽大，价格最低，中国方向没有专门优化，适合流量大但对延迟要求不高的业务，或者面向海外的跨境电商独立站。

**优质 BGP**：回程走电信 CMI、联通 CU/NTT、移动 Level3，网络繁忙时体验比普通线路明显好，个人博客和中小企业项目首选。

**精品 BGP**：三网骨干网回程，电信和联通都走 CU，移动走 CMI，晚高峰波动最小，延迟最低。对速度敏感的业务选这个，代价是带宽稍小一些。
